# KV Cache 存储回读基准测试规范

> 状态：**已发布 v1.0** · 已在沐曦 MetaX N260 完成全套验证。

## 本规范测什么

量化外部存储（远端 NVMe-oF 全闪阵列 / 本地 NVMe）对大模型推理 **KV Cache 卸载/回读** 的性能价值：当 KV Cache 装不进 GPU 显存时，把它卸载到存储、用时再回读，相比"重新计算"能快多少？不同介质差异多大？

## 适用场景

- 单机单卡 / 单机多卡的长上下文、多轮会话推理；
- vLLM + LMCache 推理栈；
- 需要在显存不足时用存储承载超大 KV 工作集的场景。

## 一句话结论

存储对 KV Cache 的价值不是"让快的更快"，而是"**让原本会退化成全量重算的超显存场景，恢复到接近显存命中的体验**"。本规范用严谨的物理读测试量化这一价值，并保证结论在不同厂商 GPU 上可被一致复现与审计。
