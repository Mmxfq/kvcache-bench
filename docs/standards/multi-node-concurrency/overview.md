# 多机多卡并发基准测试规范

> 状态：**规划中** · 本规范尚在设计阶段，欢迎补充需求。

## 本规范将测什么（拟）

面向多机多卡部署下，存储作为**共享 KV 池**时的并发承载与扩展能力：

- 多节点共享同一份 KV（远端存储相对本地盘的不可替代价值）；
- 并发规模扩展下的吞吐/尾延迟拐点；
- 多路径 / 多链路（双 100G、GDS、异步预取）对回读带宽上限的提升；
- 跨节点 KV 迁移 / 预取 / 故障恢复的端到端表现。

## 拟沿用的方法学

本规范将复用[KV Cache 存储回读规范](../kv-cache-storage/spec.md)的基础方法（SUT 登记、物理读保证、四档对照思想、指标定义、有效性清单），并在其上扩展多机维度的负载与拓扑定义。
